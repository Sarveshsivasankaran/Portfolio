## 📱 Context & Behaviour Adaptation (Mobile Intelligence)

The system automatically detects hardware context, viewport dimensions, and accessibility preferences:

1. **Hardware Pointer & Touch Sensor Adaptation (`CustomCursor.tsx` & `App.tsx`):**
   * Automatically disables custom SVG cursor rendering on coarse touchscreens (`maxTouchPoints > 0`, `pointer: coarse`).
   * Bypasses magnetic button transform calculations on touch devices to ensure native touch responsiveness with zero sticky offset traps.
2. **Viewport-Aware Capsule Scaling (`FeaturedRecordCard.tsx` & `Wins.tsx`):**
   * Dynamically caps card height to `calc(100vh - 120px)` with a custom-styled thin gold scrollbar on small screens (`<= 768px`), preventing content and action links from being cut off in the `100vh` sticky track.
   * Auto-adjusts preview media max-width (`180px` for certificates, `200px` for square cards) and scales thumbnails from `46px` to `30px`.
   * Downsizes side navigation chevrons to `36px` and moves them to `6px` margins with safe horizontal padding so controls never collide with the card body.
3. **Adaptive Projects Stream (`Projects.tsx`):**
   * Replaces hardcoded horizontal offsets with dynamic viewport measurements (`Math.min(300, viewportWidth - 48)`).
   * Dims background character opacity to `0.22` on mobile to guarantee crystal-clear card readability.
   * Eliminates right-clipping masks on mobile screens so project cards remain fully visible throughout scroll tracks.
4. **Auto-Centering Active Navigation (`Navbar.tsx`):**
   * As the user scrolls across sections, the mobile navbar horizontal pill container automatically scrolls the active category to center view using `scrollIntoView({ behavior: 'smooth', inline: 'center' })`.
5. **Reduced Motion Compliance (`@media (prefers-reduced-motion: reduce)`):**
   * Globally resets animation durations, transforms, and infinite marquees for users with vestibular sensitivities.

## 🔮 Core System Architecture

### 1. **CursorLens 3D Aperture Portal (`CursorLens.tsx`)**
* Dual-image overlay aperture with dynamic subtractive masking (`baseMaskId` and `maskId`).
* Isolates a cybernetic X-ray underlay (`beard image-inner-bdr.png`) beneath the base portrait (`outer image-bgr.png`) with **zero edge-silhouette ghosting**.
* Framed by a fluid, animated SVG glow contour.

### 2. **Spline 3D WebGL & GSAP Scroll Parallax**
* Lazy-loaded 3D WebGL canvases rendered via `@splinetool/react-spline`.
* Enhanced with GPU-accelerated **container wrapper parallax**:
  * **Hero Vortex:** Orbits **30°** on scroll progression.
  * **Arsenal Torus:** Rotates **-40°** counter-directionally on section entry for maximum spatial depth.

### 3. **Hall of Fame & 3D Interactive Record Capsules (`Wins.tsx`)**
* High-impact milestone showcase with horizontal carousel navigation, keyboard/touch support, and dynamic record counters.
* Powered by `FeaturedRecordCard.tsx` featuring:
  * **3D Gyroscope / Mouse Tilt:** Interactive spring physics with light sheen reflection.
  * **Thumbnail Ribbon Gallery:** Auto-advancing slides with page-flip animations.
  * **Ultra High-Res Lightbox Modal:** Full-bleed inspection portal with responsive aspect ratio preservation.

### 4. **Hunter Profile & Community Leadership (`About.tsx`)**
* Cybernetic profile matrix detailing core stats, college journey, and student governance:
  * **Intellexa REC Club:** Vice President (2026–2027), Titanium 2K26 SPOC, HackRush Triple Podium Mentor.
  * **CodeSapiens:** Keynote Speaker (Feb 2K26) on developer mastery and Event Speaker Manager.

### 5. **Live GitHub Stats Scanning (Arsenal & Skills)**
* Real-time querying of GitHub REST API via `@tanstack/react-query 5`.
* Dynamically boosts skill proficiency gauges (`+2%` per matching repository, capped at `95%`) with animated glow meters.

### 6. **Supabase Realtime Activity Stream (`WinsGallery.tsx`)**
* Real-time activity feed pulling authenticated accomplishments from **Supabase PostgreSQL** via Realtime subscriptions.
* Features multi-image collages, badge tags, external LinkedIn links, and fallback to pre-cached data (`linkedinPosts.ts`).
* Includes a protected admin management portal (`/admin/activities`) for adding, editing, and managing posts.

### 7. **Recursive Google Drive Synchronization (`Events.tsx`)**
* Dynamic photo galleries for college hackathons, technical fests, and workshops.
* Iterative **Breadth-First Search (BFS)** discoverer (`useDriveImages.ts`) that traverses nested Google Drive directories with 15-second cache invalidation and offline fallback.

### 8. **Silent Quest Transmission (`Contact.tsx`)**
* Direct **Web3Forms** silent background dispatch.
* Emits a reactive **System Quest Portal** upon completed transmission, with offline localStorage queuing and seamless `mailto:` fallback.

## 🔑 Setup & Environment Configuration

Create a [`.env`](file:///d:/Program%20files/Portfolio/.env) file at the root of the project to initialize the system coordinates:

```env
# GitHub API (stats scanning)
VITE_GITHUB_TOKEN=your_github_personal_access_token

# Google Drive API (event gallery synchronization)
VITE_GOOGLE_API_KEY=your_google_cloud_api_key

# Web3Forms API (silent contact form delivery)
VITE_WEB3FORMS_ACCESS_KEY=your_web3forms_access_key

# Supabase (realtime LinkedIn activity feed & admin)
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### Feature Fallback Logic:
* **Web3Forms:** Enables silent background form submissions. Automatically falls back to a stashed queue and `mailto:` launcher if unconfigured or offline.
* **Google API:** Synchronizes dynamic image folders. Gracefully falls back to bundled high-res offline image grids (`driveImages.ts`).
* **GitHub Token:** Queries repository counts and languages to dynamically scale skill proficiency bars. Falls back to default system values if rate-limited.
* **Supabase:** Subscribes to live database modifications. Falls back cleanly to authoritative static fallback posts (`linkedinPosts.ts`).

## 🏃 System Invocations (Execution Commands)

Execute the following commands in PowerShell or your terminal of choice:

### 1. Install Guild Dependencies
```bash
npm install
```

### 2. Launch Local Dev Realm (HMR Active)
```bash
npm run dev
```
The server will start with hot-module replacement at **`http://localhost:3000`** (or designated Vite port).

### 3. Run Test Suite (Vitest)
```bash
npm test
```
Executes the [Vitest](https://vitest.dev/) suite verifying feed synchronization, admin policies, activities collage, and project ordering (**40 passed tests**).

### 4. Compile Production Artifacts
```bash
npm run build
```
Executes TypeScript type checking (`tsc && tsc -p tsconfig.api.json`) and bundles optimized production assets via Vite into `dist/`.

### 5. Local Production Preview
```bash
npm run preview
```
Serves the compiled production bundle locally to verify build performance, code-splitting, and routing.
